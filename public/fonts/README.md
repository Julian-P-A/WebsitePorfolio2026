# Font assets

These Latin WOFF2 files are served locally using CSS `@font-face`. Bricolage
Grotesque was downloaded from Google Fonts; the other families were recovered
from the project's existing font cache. They include the accented letters and
punctuation used by the Spanish and English pages.

- `bricolage-grotesque-latin-variable.woff2`: Bricolage Grotesque, weights 400–800.
- `geist-latin-variable.woff2`: Geist, weights 100–900.
- `instrument-serif-latin-regular.woff2`: Instrument Serif, normal, weight 400.
- `instrument-serif-latin-italic.woff2`: Instrument Serif, italic, weight 400.
- `jetbrains-mono-latin-variable.woff2`: JetBrains Mono, weights 400–800.

All fonts use the SIL Open Font License 1.1; see `OFL.txt` for copyright
notices and license terms.

There are no external font requests during development-server startup,
production builds, or browser visits.
